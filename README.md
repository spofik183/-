# STRIKEPOINT ONLINE

Браузерный 3D multiplayer FPS-прототип.

## Запуск

1. Установи Node.js 18+.
2. Открой терминал в папке проекта.
3. Выполни:

```bash
npm install
npm start
```

4. Открой:
http://localhost:3000

Для теста мультиплеера открой игру в двух вкладках или на двух устройствах в одной сети.

## Управление

- WASD — движение
- мышь — обзор
- ЛКМ — стрельба
- Shift — спринт
- R — перезарядка
- TAB — таблица игроков

## Что уже есть

- настоящий Socket.IO мультиплеер
- синхронизация игроков
- FPS-управление
- hitscan-стрельба
- урон / HP
- убийства / смерти
- респавн
- таблица игроков
- kill feed
- мини-карта
- 3D-карта с укрытиями
- перезарядка и боезапас
- локальная коллизия с объектами

## Деплой

Проект подходит для Railway / Render / любого Node.js-хостинга.
Команда запуска: `npm start`
Порт берётся из `process.env.PORT`.
